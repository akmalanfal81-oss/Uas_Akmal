## 📱 Topik Aplikasi
**Aplikasi Martabak dan Terang Bulan** adalah platform pemesanan digital yang menjual berbagai varian martabak dan terang bulan sebagaimana mestinya. Aplikasi ini dirancang untuk memudahkan pelanggan dalam memilih dan memesan menu favorit mereka. 

Isi dari aplikasi ini mencakup:
1. **Katalog Menu:** Menampilkan informasi lengkap mengenai menu martabak dan terang bulan (nama, harga, gambar, dan deskripsi).
2. **Manajemen Pengguna:** Menyimpan dan mengelola data pengguna melalui sistem *Login* dan *Register*.
3. **Statistik Populer:** Menampilkan visualisasi diagram (bar chart) yang interaktif untuk menu martabak dan terang bulan yang paling populer/terlaris.

---

## ✨ Fitur Utama
* **UI/UX Responsif:** Antarmuka yang rapi dan mendukung tampilan *landscape* (menggunakan ScrollView & RecyclerView).
* **Autentikasi (Modul 4 & 5):** Sistem perpindahan halaman (*Intent*) dan validasi input (*If-Else*) pada halaman Login dan Register.
* **Pencarian Menu (Modul 6):** Fitur pencarian data menu secara *real-time* menggunakan algoritma **Linear Search** berbasis *Array*.
* **Pengurutan Menu (Modul 7):** Fitur untuk mengurutkan daftar menu (Abjad A-Z / Z-A atau Harga) menggunakan algoritma **Bubble Sort**.
* **Pemantauan Sistem (Modul 9):** Implementasi penanganan *error* (*Try-Catch*) dan perekaman aktivitas *lifecycle* aplikasi di latar belakang menggunakan **Logcat** Android Studio.
